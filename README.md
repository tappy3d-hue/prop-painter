# Prop Painter

Roblox Studio 用のプラグインです。木・岩・草・小物といった「プロップ」をライブラリに登録し、単体配置／ペイントブラシ／消しゴム／範囲一括生成の4つの方法でワークスペースへ効率よく散布できます。ランダムなサイズ・回転、複数プロップの重み付き抽選、配置後の再ランダム化・再適用にも対応しています。

- Version: `0.7.2`
- 対応環境: Roblox Studio（プラグインとしてインストール）
- UI言語: 日本語
- 配布形式: `PropPainter_PluginPackage.rbxmx`（そのままPluginsフォルダに置けば動作。`PropPainter.plugin.lua`は中身のスクリプトのみを取り出したソースコード版で、外部依存はなくこちらを直接置いても動作します）

## 特徴

- **プロップライブラリ**: `ServerStorage` 内にパレット（フォルダ）単位でプロップを保存し、サムネイル付きグリッドで一覧表示。
- **4つの配置モード**: 単体配置（左右ドラッグで回転）、ペイントブラシ、消しゴム、選択範囲への一括生成。
- **ランダマイズ**: サイズ・Y軸回転をプロップごとに範囲指定してランダム化。プロップ単位で個別設定（オーバーライド）も可能。
- **複数プロップの重み付き抽選**: 複数選択したプロップに0〜2の重みを設定し、出現比率をコントロール。
- **面追従**: 設置面の法線に合わせて自然に傾ける／常に垂直に立てる、をプロップ単位で切替可能。
- **配置Pivot編集**: プロップごとに「地面に接する基準点」をハンドルで自由に調整可能。
- **生成済みプロップの管理**: 配置済みプロップを種類ごとに一覧化し、まとめて選択・再適用・再ランダム化。
- **プリセット**: 選択プロップと各種設定をまとめて保存・呼び出し。
- **Undo/Redo対応**: すべての生成・削除操作は Studio の変更履歴（Ctrl+Z）に対応。

## インストール

1. `PropPainter.plugin.lua` を Roblox Studio のプラグインフォルダに配置します。
   - Windows: `%LOCALAPPDATA%\Roblox\Plugins`
   - macOS: `~/Documents/Roblox/Plugins`
2. Studio を再起動する（または「プラグイン」タブ →「プラグインフォルダ」から手動で反映）。
3. Studio 上部の「プラグイン」タブに **Prop Painter** ボタンが表示されます。クリックしてドックウィジェットを開閉します。

> Studio のプラグインマーケットプレイスへ公開する場合は、このファイルを1本のスクリプトとしてアップロードしてください（外部依存なし）。

## 基本的な使い方

1. ワークスペース上でプロップにしたい Part または Model を選択する。
2. 「ライブラリ」タブの **「選択物を個別プロップとして追加」** をクリックしてライブラリへ登録する。
3. 登録したプロップをグリッドから選択する（複数選択も可）。
4. 「配置」タブへ移動し、サイズ・回転・ブラシ半径などを設定する。
5. 「単体配置」「ペイント」「消しゴム」のいずれかのモードを開始し、ワークスペース上をクリック／ドラッグして配置する。
6. 配置したプロップは「生成済み」タブでまとめて確認・再適用・再ランダム化できる。

## ライブラリタブ

| UI要素 | 説明 |
| --- | --- |
| パレット切替ボタン | プロップの分類フォルダ（パレット）をクリックで巡回切替。存在しない場合は自動的に「Default」パレットが作成される。 |
| 選択物を個別プロップとして追加 | Studio 上で選択中の Part / Model を複製し、現在のパレットへプロップとして登録する。 |
| 更新 | ライブラリの表示を再読込する。 |
| 単一選択 / 複数選択 | プロップカードのクリック挙動を切替。複数選択モードでは Ctrl または Shift を押しながらのクリックでも追加選択できる。 |
| 配置Pivotを編集 | 選択中プロップの設置基準点（Pivot）を編集する（後述）。 |
| 配置設定へ | 「配置」タブへ移動する。 |
| 有効プロップ：重み・個別設定 | 選択中の各プロップの出現重みと、サイズ／回転／面追従の個別オーバーライドを設定するパネル。 |
| プロップカード | サムネイル・名前・出現重み・選択トグル（+/✓）を表示。カードのクリックで主選択、右上の「+」で複数選択への追加/解除。 |

プロップカードおよび個別設定パネルの重み欄は、**右クリックで 1.00 にリセット**できます。

## 配置タブ

配置タブは折りたたみ可能なカテゴリで構成されています。

### 配置モード
「単体配置」「ペイント」「消しゴム」を直接切替えるボタン群。

### プリセット
選択プロップと配置設定一式を名前を付けて保存・読込・削除（詳細は [プリセット](#プリセット) 参照）。

### サイズ・回転・面追従
| 項目 | 内容 |
| --- | --- |
| サイズ 最小/最大 | 配置時のランダムスケール範囲（0.05〜20倍）。 |
| Y回転 最小/最大 | 配置時のランダムなY軸回転角度範囲（-360°〜360°）。 |
| 単体回転 スナップ角度 | 単体配置でドラッグ回転する際のスナップ角度。 |
| 単体回転スナップ ON/OFF | ドラッグ回転を指定角度単位にスナップするか切替。 |
| 面に沿わせる ON/OFF | 設置面の法線に合わせて傾けるか、常に垂直に立てるかを切替。 |

### ペイントブラシ
| 項目 | 内容 |
| --- | --- |
| ブラシ半径 | 円形ブラシの半径（Stud）。 |
| 1スタンプの生成試行数 | マウス移動1ステップあたりにブラシ範囲内で試行する生成回数。 |
| 最小間隔 | プロップ同士の最小距離。ONの場合、既存プロップおよび同一ストローク内の配置と近すぎる位置には生成しない。 |
| ペイント方式：密度維持/追加 | 「密度維持」は既存の生成済みプロップも間隔チェックに含める。「追加」は新規ストローク内のみで間隔をチェックする。 |
| 最小間隔チェック ON/OFF | 間隔チェックの有効/無効。 |

### 複数プロップの出現率
複数選択したプロップの主選択（アクティブ）プロップの重みを調整するショートカット欄。詳細な重み設定はライブラリタブの「有効プロップ」パネルで行う。

### 選択範囲へ一括生成
| 項目 | 内容 |
| --- | --- |
| 一括生成数 | 一度に生成する個数（1〜1000）。 |
| 一括生成の対象面：上面のみ/全表面 | 選択した Part/Model の上面だけに生成するか、6面すべてを面積比で抽選するかを切替。 |
| 選択範囲へ一括生成 | ワークスペースで選択中の Part/Model の表面上にランダムな位置・回転でプロップをまとめて生成する。 |

### Pivotとライブラリ
選択プロップの配置Pivot編集への入口と、ライブラリタブへ戻るボタン。

## 配置モードの詳細

### 単体配置
1. プロップを選択して「単体配置」を開始（もう一度押すと終了）。
2. マウスカーソル位置にプレビューが表示される。
3. 左クリックで位置を確定しつつ、ボタンを離さずに左右にドラッグするとY軸回転を調整できる（Shift押下で微調整）。
4. 左ボタンを離すと確定配置し、次のプレビュー（新しいランダムシード）が表示される。

### ペイント / 消しゴム
1. 「ペイント」または「消しゴム」を開始すると、マウス位置に円形のブラシ表示（青＝ペイント、赤＝消しゴム）が出る。
2. 左ボタンを押しながらドラッグすると、ブラシ半径内にランダムな位置・回転でプロップを連続生成（ペイント）、または既存の生成済みプロップを削除（消しゴム）する。
3. 一定距離移動するごとにスタンプ処理が実行される。
4. ボタンを離すと一連のストロークとして Undo 履歴に1件記録される。

### 選択範囲へ一括生成
ワークスペースで対象の Part/Model を選択した状態で実行すると、面積に比例した抽選で表面上にランダム配置される。「上面のみ」または「全表面（6面）」を選べる。

## プリセット

- **保存**: 現在の配置設定・選択プロップ（重み・個別オーバーライド含む）・パレット名を、入力した名前で保存する。
- **読込**: 保存済みプリセットを選び、設定・プロップ選択・パレットを復元する。プリセット名はボタンをクリックすると巡回切替できる。
- **削除**: 選択中のプリセットを削除する。

プリセットはプラグイン設定（`plugin:SetSetting`）に保存され、Studio・ファイル間で永続化されます。

## 生成済みタブ（管理）

配置済み（生成済み）のプロップを パレット名/プロップ名 単位でグループ化して一覧表示します。

| ボタン | 説明 |
| --- | --- |
| 一覧を更新 | 最新の生成状況を再スキャンする。 |
| すべて選択 | 生成済みプロップ全てを Studio 上で選択する。 |
| 設定を再適用 | 選択中の生成済みプロップに対し、現在の配置設定（サイズ・回転範囲など）を使って元プロップから再生成する（位置は保持）。 |
| 再ランダム化 | 選択中の生成済みプロップを、新しい乱数シードで再生成する（サイズ・回転が変わる）。 |
| 一覧の項目クリック | その種類のプロップをまとめて Studio 上で選択する。 |

「再適用」「再ランダム化」は元のプロップ（`ServerStorage` 上のアセット）が見つからない場合はスキップされ、ステータス欄に件数が表示されます。

## 配置Pivotの編集

デフォルトでは、プロップのバウンディングボックス底面が接地点として使われます。任意の点を接地点にしたい場合はPivot編集を使用します。

1. ライブラリでプロップを選択し、「配置Pivotを編集」をクリック。
2. オレンジ色のハンドルが表示されるので、Studio の移動/回転ツールでハンドルを操作する。
3. 「底面へリセット」でバウンディングボックス底面に戻せる。
4. 「保存して終了」で確定、「キャンセル」で破棄。

保存されたPivotはプロップの属性（`PropPainterPlacementPivot`）として記録され、以降の配置すべてに反映されます。

## キーボードショートカット

| キー | 動作 |
| --- | --- |
| `[` | 単体配置中はサイズを縮小、ペイント/消しゴム中はブラシ半径を縮小 |
| `]` | 単体配置中はサイズを拡大、ペイント/消しゴム中はブラシ半径を拡大 |
| `Shift` + `[` / `]` | 上記の微調整版 |
| `Esc` | 実行中の配置モード／Pivot編集を終了 |
| `Ctrl` または `Shift`（ライブラリのクリック時） | 複数選択モードでなくてもプロップカードを追加選択 |

## データの保存場所

| 場所 | 内容 |
| --- | --- |
| `ServerStorage/PropPainterLibrary/<パレット名>/` | 登録済みプロップの原本。パレット未指定時は `Default` フォルダが自動作成される。 |
| `Workspace/PropPainterOutput/<パレット名>/<プロップ名>/` | 配置（生成）されたプロップのコピー先。 |
| プラグイン設定 (`plugin:SetSetting`) | 各種スライダー値・プリセット・最後に使用したパレット名を保存（キー: `PropPainterSettingsV1`, `PropPainterPresetsV1`）。 |

生成されたインスタンスには次のような属性が付与されます（管理・再適用機能で利用）。

- `PropPainterGenerated` : 生成物であることを示すフラグ
- `PropPainterAssetId` : 元プロップの一意なID
- `PropPainterAssetName` / `PropPainterPalette` : 元プロップ名・パレット名
- `PropPainterSeed` / `PropPainterScale` / `PropPainterYaw` : 生成時の乱数シード・スケール・Y回転
- `PropPainterMode` : 生成方法（`Single` / `Paint` / `Batch` / `Reapply` など）
- `PropPainterPosition` / `PropPainterNormal` : 生成位置と法線
- `PropPainterAlignToSurface` : 面追従の適用有無
- `PropPainterVersion` : 生成時のプラグインバージョン

プロップ（ライブラリ側アセット）にも以下の属性が付きます。

- `PropPainterAssetId` : 一意ID
- `PropPainterWeight` : 出現重み（0〜2）
- `PropPainterPlacementPivot` : 配置Pivot（CFrame）
- `PropPainterOverrideEnabled` とその関連（`PropPainterScaleMin/Max`, `PropPainterYawMin/Max`, `PropPainterAlignToSurface`）: プロップ単位の個別設定

## 注意点・既知の制約

- ライブラリ内（`ServerStorage/PropPainterLibrary`）や生成先（`Workspace/PropPainterOutput`）内のインスタンスは、配置対象の選択元として使用できません。
- 一括生成・ペイントの対象になるのは `BasePart` を含む `Model` または `BasePart` のみです。
- ペイント/消しゴムの「最小間隔」チェックは空間分割インデックスによる近似判定です。
- 生成物はすべて `Anchored = true` になります。
